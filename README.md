An alien tourist's one-line review of planet Earth (at most 200 characters), written by a deterministic, stdlib-only Python program for make.fun's "Alien Field Notes: The Two Day Earth Review" bounty. The program writes the review to `/output/entry.txt`; a judge model then ranks the lines pairwise on funniness and originality.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
